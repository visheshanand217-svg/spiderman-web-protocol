# SPIDERMAN — Live Web Protocol

A Marvel/Spider-Man inspired event landing page for the GFG Student Chapter, Bennett University.

## Included
- User-supplied spider artwork used as the visual background
- Live animated web canvas background
- Floating particles and cursor-reactive movement
- Cinematic SPIDERMAN hero section
- Mission / challenge cards
- Event timeline
- Registration CTA + demo form
- Responsive mobile layout
- No build tools required

## Run locally
Open `index.html` directly in a browser.

## Before submission
Replace the fictional event times, challenge copy, and demo registration form with the actual event information / registration link.
